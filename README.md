Project Description

ADV-EDITS is a photography and videography service website that provides photo and video coverage for weddings, birthdays, and other special events. The system allows clients to explore sample photos and videos, view available service packages, make reservations, check schedules through a calendar, and process payments.

The system will also include an administrator dashboard where the admin can manage reservations, monitor schedules, view calendar events, and organize booking information. Laravel will be used for backend development, while Filament will serve as the content management system for managing the website's data and administrative functions.
